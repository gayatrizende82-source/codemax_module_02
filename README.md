---

## 📌 About This Project

This repository contains the Python Mini Project developed as part of **Module 02 – Python Mini Project** of the Codomax Internship Program.

The main objective of this project is to apply Python programming concepts to develop a simple Student Grade Calculator.

This project accepts student details and subject-wise marks and helps calculate the student's academic performance.

---

## 📚 Project Description

### 1️⃣ Student Name Input

- **Accepts the student's name from the user.**
- **Validates that the name is not empty.**

### 2️⃣ Subject-wise Marks

The project includes five subjects:

- **English**
- **Mathematics**
- **Science**
- **Computer**
- **Social Science**

### 3️⃣ Marks Validation

- **Accepts marks between 0 and 100.**
- **Handles invalid inputs.**
- **Uses 35 marks as the passing criteria.**

### 4️⃣ Result Calculation

- **Calculates the total marks.**
- **Calculates the percentage.**
- **Displays the final result and grade according to the program logic.**

## ⚙️ How to Run the Project

**Step 1:** Install Python 3 on your computer.

**Step 2:** Download or clone this repository.

**Step 3:** Open the project folder in Visual Studio Code.

**Step 4:** Open the VS Code Terminal.

**Step 5:** Run the following command:

```bash
py main.py
```

**Step 6:** Enter the student name and subject-wise marks.

**Step 7:** View the calculated result.
